# 기존 사이트와 신규 강의 화면의 스타일 통일

기준은 기존 app/classes/page.tsx와 components/classes/ClassCard.tsx의 실제 화면 및 app/globals.css다. 신규 페이지를 별개의 디자인으로 만들지 않고 기존 Header·Footer·Pretendard 글꼴을 그대로 사용한다.

## 공통 기준

- 검정 배경과 상단의 낮은 농도 파란 조명
- 본문 Pretendard, 15px, 행간 1.6~1.7 / 기존 수업 신청 화면의 입력·버튼 크기 15px
- 제목 PC 28px, 태블릿 24px, 모바일 20px / 카드 제목 16~18px
- 본문 흰색 60%, 보조 정보 흰색 40%, 제목 흰색
- 기존 파란 버튼: rgba(0,122,255,.85) → rgba(0,100,220,.75), 테두리와 안쪽 밝은 선
- 입력창: 흰색 3% 배경·10px 모서리 / 버튼 12px / 패널·카드 20px
- PC 콘텐츠 폭 최대 1400px, 좌우 24px / 모바일 좌우 16px

로그인·비밀번호 설정과 주문 상세는 기존 사이트의 폼처럼 읽기 쉬운 좁은 폭을 유지한다. 카드에 없는 이미지·강의 정보는 임의로 추가하지 않는다.

## 적용 범위와 병합

components/lectures/lecture-site.css를 두 신규 route layout에서만 불러온다. 모든 선택자는 .lecture-site 아래로 제한하며 app/globals.css와 기존 수업 신청·학생 로그인·Header·Footer 코드는 수정하지 않는다. 12개 신규 강의/관리자 페이지에서 기존 시제품의 흰색 입력창·남색 카드와 기본 버튼 표시를 교체했다.

강의 선택·주문·관리자 처리·로그인·세션·API·DB 구조는 그대로 유지한다. 공통 스타일 파일만 바꿔도 GitHub 검사가 실행되도록 workflow의 경로 조건에 components/lectures/**를 포함했다.

## 화면 검증

2026-11-04 로컬 가상 DB에서 기존 수업 신청 화면과 새 화면의 같은 PC 브라우저 크기를 비교했다. 제목은 Pretendard 28px·흰색, 콘텐츠 폭은 기존 수업 신청의 1400px에 맞췄다. 카드 선택 시 합계가 갱신되고 비회원 주문 버튼은 비활성 상태를 유지한다. 로그인→회원가입 전환과 입력 필드 표시를 확인했다. 모바일 390×844에서 제목 20px·입력창·버튼·가로 넘침 없음도 확인했다. 기존 Header의 모바일 배치는 이번 변경 범위에 포함하지 않는다.

화면 증빙은 저장소 밖 outputs에 보관한다. 실제 강의 영상·청구·권한 검증은 별도 기능 검사 기록을 따른다.
